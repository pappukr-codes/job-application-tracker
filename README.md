# 💼 Job Application Tracker

A modern, fast, and responsive web application built with **Vanilla JavaScript** to help job seekers organize, track, and manage their job applications in one place.

## 🌟 Key Features

- **📊 Dynamic Dashboard:** Live counters for Total, Applied, Interview, Offer, and Rejected applications.
- **⚡ Full CRUD Logic:** Add new applications, edit existing entries, and delete cards with instant UI updates.
- **🔍 Multi-Criteria Search & Filter:** Filter by status tabs or search in real-time by company name or job role.
- **💾 LocalStorage Persistence:** Single Source of Truth (SSOT) architecture keeps data synced and saved across browser sessions.
- **✨ Smooth Visual Feedback:** Built-in form processing states, loading delays, and custom CSS entry animations.
- **🚀 High Performance:** Zero external dependencies, achieving **90+ Chrome Lighthouse scores** across Performance, Accessibility, Best Practices, and SEO.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Properties, Grid & Flexbox)
- **Scripting:** Vanilla JavaScript (ES6+, DOM Manipulation, Array Methods, LocalStorage API)
- **Deployment:** Vercel
